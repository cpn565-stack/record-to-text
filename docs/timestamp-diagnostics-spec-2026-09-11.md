# 時間標記與完成工作診斷

2026-09-11。依使用者指示直接規劃並實作；講者／姓名不在本輪範圍。

## 行為

- 雲端請求附上實際片段起訖及預期的五分鐘區間，最後一個區間不得超過片段終點。
- 每個完整回應在建立檢查點前檢查時間標記。只校正可由已知片段邊界確定的起訖；不改動對話文字。
- 若缺少區間、時間倒退、區間重疊或不在片段內，移除該片段不可靠的時間標記，改成實際片段範圍，加上「段內時間待核對」提示。不得按字數插入時間、猜測位置或額外呼叫模型。
- 時間待核對與音訊缺口分開：不把格式異常當成漏錄，不改成轉錄失敗；完成工作及最近工作顯示提示。
- 新舊檢查點續跑均套用同樣的時間檢查，已完成音訊不重送。既有六份使用者文字檔不覆寫。

## 診斷

- 完成工作保留音訊長度、各段範圍、前處理、雲端呼叫總時間、可觀測的認證／上傳／輪詢／生成請求／退避等待耗時，以及固定分類的重試原因。
- 生成請求耗時包含傳輸及伺服器處理，不能解釋成純模型運算時間；無法測量的欄位保持未知。
- 保留本次因輸出上限捨棄並切分的父段耗時；重用檢查點的資料標明來自前次執行，不計為本次耗時。
- 診斷只含數值、固定枚舉及範圍，不保存 Prompt、詞庫、逐字稿、原始錯誤訊息、雲端 URL 或憑證。沿用最近工作數量限制，重開 App 後仍可複製。
- 新增欄位可選，舊紀錄與 publication intent 可正常載入。
