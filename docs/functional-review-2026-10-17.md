# 功能檢視與 build 13 修正

檢視日期：2026-10-17。範圍為本機 Qwen／Google AI Studio／Vertex 的模型設定、長音分段、重試與取消、工作續跑與輸出保存；依據目前程式及自動測試，不代表已重新驗收真實長錄音的辨識品質。

## 本次完成

### 網路重試等 20 秒，並可立刻重試

- 可重試的網路錯誤，原本約 15／45／120 秒並加上隨機延遲，改成每次固定 **20 秒**。
- 等待時顯示逐秒倒數與「立刻重試」。按下後喚醒目前等待，繼續同一工作、同一未完成片段；連按不會建立多筆工作或並行請求。
- 手動重試仍共用既有發送次數及整段期限。取消優先；已送出的 HTTP 請求不會因按鈕被複製。
- 如果網路偵測仍顯示離線，可以手動嘗試一次；之後再遇到錯誤仍回到正常等待。
- 20 秒指網路失敗後的重送倒數。離線時的等候、Google 明確要求的服務冷卻、已送出請求等待模型回答的時間，仍有各自的規則。
- 狀態日誌區分等網路、等服務重試、等 Google 回應，避免等待連線時仍寫成 Google 正在轉錄。

主要程式：`CloudNetworkRecoveryPolicy.swift`、`TranscriptionEngine.swift`、`AppViewModel.swift`、`MainView.swift`。

### 自訂模型選單可以正常開啟，輸入完成才套用

確認舊設定的 Picker 選到 `custom` 時 setter 沒有改變任何狀態，因此從預設模型無法打開輸入欄。已有自訂模型時，原 TextField 每打一個字就更改實際設定及尚未開始的工作；清空則立刻切回預設並隱藏欄位。

AI Studio 與 Vertex 現在共用 `GeminiModelPicker`：

- 選「自訂模型 ID…」會打開編輯欄，並保留目前生效模型。
- 草稿可以清空或修改；按「套用」或 Return 才將非空、去除首尾空白的 ID 套用一次。
- 切回預設選項會直接套用；主視窗快速選單改變模型時，設定視窗也會同步。
- 沿用既有規則：尚未開始的新工作跟隨設定；執行中及檢查點續跑工作維持原設定。

## 已核對的保護機制

- 完成片段有檢查點；續跑驗證已完成文字及原工作設定，缺失時不悄悄從頭重做。
- 切換模型不改動執行中與檢查點工作的設定。
- 取消、工作終止及完成稿保存有回歸測試；恢復後需使用者手動啟動，避免開 App 就重送。
- 這次維持既有逐字稿格式，未啟用摘要或結構化 JSON。
